# RespuestasRapidas Tests

Mobile E2E test framework using **Appium 2 + WebDriverIO + TypeScript**.

## Setup

```bash
npm install
```

## Run tests

```bash
npm test
```

## Lint / Format

```bash
npm run lint
npm run format:check
```

## Structure

- `tests/mobile/specs/` - Appium specs
- `tests/mobile/pages/` - Page objects
- `tests/mobile/apks/` - APKs under test
- `shared/utils/mobile/` - helpers
