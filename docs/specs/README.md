# Specs by branch

Each working branch generates its folder in docs/specs/<branch-name>/ with SDD artifacts:

- 01-understanding.md: summary of what and why.
- 02-spec.md: user story + criteria.
- 03-questions.md: questions/assumptions and answers.
- 04-gherkin.feature: BDD scenarios.
- 05-test-plan.md: Appium E2E test plan.

The folder name must match the active branch (git branch --show-current).
