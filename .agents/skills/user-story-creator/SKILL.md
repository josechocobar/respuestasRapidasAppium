# User Story Creator Skill (Appium + TypeScript)

Converts requirements into INVEST user stories for mobile automation.

## Format

```markdown
### User Story: [Title]

**As a** [Role: mobile user / QA / team]
**I want** [Action or flow in the app]
**So that** [Business value]

#### Acceptance Criteria
1. Given [context], when [action], then [result in app].
2. Input data validation.
3. Navigation and visible states verifiable.
```

## Rules

- Focus on mobile flows and criteria verifiable through E2E tests.
- Code in English.
```
